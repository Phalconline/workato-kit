# Gemini CLI notes

The rules are in `AGENTS.md`, imported above. Edit rules there, not here. This part holds only
what is specific to Gemini CLI. Not verified: the kit was not run with Gemini CLI, so how
Gemini CLI reads these files and signs in to a server is not verified.

- The project's MCP servers are in `.gemini/settings.json`, generated by
  `scripts/sync_harness.py` from `.agents/mcp.json`. Sign in to each with `/mcp auth <name>`, for
  example `/mcp auth workato-airo-mcp-server`, while the Dev environment is active in the
  browser.
- Procedures are Agent Skills in `.agents/skills/`.
- The kit configures no hook for Gemini CLI, so the guard of this repository
  (`scripts/guard_wk.py`) does not run here. The rules **No package commands** and **Secrets** in
  `AGENTS.md` are the only thing that stops a forbidden `wk` command: follow them before every
  shell command.
- `.geminiignore` lists the files that hold credentials: `profiles.env`, `.wk/`, `.env`,
  `.env.*`, and the `master.key` and `settings.yaml` of a connector project. Never read those
  files by another way.
- Temporary files go to `tmp/` (see "Working cache" in `AGENTS.md`).
